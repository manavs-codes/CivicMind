# CivicMind

CivicMind is an intelligent civic complaint management
platform designed to improve communication between
citizens and local authorities.

## Project Goals

- Allow citizens to submit civic complaints.
- Track complaint resolution status.
- Help administrators manage complaints.
- Provide insights through analytics.
- Explore AI-assisted complaint classification.

## Technology Stack

- Python
- FastAPI
- MongoDB Atlas
- Streamlit
- Git and GitHub

## Project Status

Under active development.
